# Экскурсия за 3 минуты

Что показать, если на проект есть три минуты. Подготовка один раз: `pip install -r requirements.txt`,
в `.env` задан `ANTHROPIC_API_KEY` (для Telegram ещё `BOT_TOKEN` и `OPERATOR_CHAT_ID`), `pytest` зелёный,
терминал открыт в папке проекта.

## 1. Задача (20 секунд)

«Малому бизнесу в мессенджер приходят одни и те же вопросы. Бот отвечает только по
утверждённой базе знаний, а всё, чего в базе нет, передаёт человеку и доставляет его
ответ клиенту. Всё логируется, есть метрики: сколько закрыл бот, что спрашивают чаще».

## 2. Живой диалог (60 секунд)

```bash
python -m support_bot --console
```

Задать подряд: «Сколько стоит замена масла?», «Работаете ли в воскресенье?»,
«Поможете оформить ОСАГО?» и `/stats`. Показать, что первые два ответа взяты из статей
базы (строка `[статья: …]`), третий ушёл оператору с номером обращения, а статистика это
отразила.

## 3. Как это устроено (60 секунд)

- `support_bot/assistant.py` — одна функция `handle`: приветствие → поиск → фильтр по доле
  совпавших слов → модель → «ответить или передать». Всё логируется в SQLite.
- `support_bot/llm.py` — `AnswerSchema` и `client.messages.parse(...)`: модель обязана вернуть
  JSON `{covered, answer}`, поэтому решение «передать оператору» принимается по полю, а не
  по догадке из текста. Системный промпт запрещает придумывать факты вне выдержек.
- `support_bot/search.py` — BM25 без внешних сервисов, свой стеммер для русского.
- `tests/` — 30 тестов без сети: пять вопросов закрываются, шестой эскалируется,
  журнал пишется, страница метрик отвечает, n8n-workflow синхронен с базой.

## 4. Telegram и оператор (40 секунд, если есть сеть)

Запустить `python -m support_bot`, с телефона задать вопрос вне базы, показать карточку
«🆘 Обращение #N» в чате оператора, ответить на неё reply-ем, показать, что клиент получил
«Ответ оператора: …».

## 5. Метрики и n8n (20 секунд)

`python -m support_bot --metrics` → http://127.0.0.1:8000. Затем `n8n/support-bot.workflow.json`:
тот же сценарий собран из узлов n8n (Telegram Trigger → Code → Basic LLM Chain + Anthropic →
IF → Telegram), файл генерируется из базы знаний.

## Частые вопросы

- **Почему BM25, а не эмбеддинги?** База маленькая (десятки статей), вопросы короткие, BM25 с
  тегами покрывает их без внешних сервисов и за миллисекунды. Интерфейс `KnowledgeSearch`
  один, эмбеддинги подключаются заменой класса.
- **Как защищаетесь от выдумок модели?** Модель видит только найденные выдержки, промпт
  запрещает добавлять факты, а поле `covered` в структурированном ответе отправляет
  сомнительные случаи человеку. Плюс порог по совпадению слов отсекает мусор до модели.
- **Что будет, если API недоступен?** Исключение перехватывается, обращение уходит оператору,
  клиент получает тот же текст о передаче. Тест `test_llm_error_falls_back_to_operator`.
- **Сколько это стоит?** Claude Haiku 5.5: 0,10 $ за миллион входных токенов и 0,50 $ за
  миллион выходных, один ответ бота — около тысячи токенов, то есть доли копейки.
- **Что бы улучшили?** Контекст диалога, эмбеддинги для синонимов, вебхук вместо polling,
  роли операторов и SLA по времени ответа.
